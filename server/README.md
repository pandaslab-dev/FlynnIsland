# Flynn Island Multiplayer Server

## Run Locally

1. Open a terminal in this folder:
   - `cd server`
2. Install dependencies:
   - `npm install`
3. Start the server:
   - `node server.js`

The server runs on port `3000` by default:
- `http://localhost:3000`

Optional:
- Set a custom port with `PORT`, for example:
  - `PORT=4000 node server.js`
